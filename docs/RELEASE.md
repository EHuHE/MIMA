# 发布检查清单

本仓库在竞赛答辩结束并确认规则允许之前保持私有。任何公开可见性变更都必须作为独立操作，
不能与普通代码推送捆绑。

公开前执行：

1. 从远程重新克隆到新的临时目录。
2. 运行单元测试、四候选验证、两条配方重放和两个 GHDL 仿真。
3. 运行 `mima-release-audit --root .`，要求零违规。
4. 确认 Git 历史只有预期文件，作者邮箱为 GitHub no-reply 地址。
5. 确认仓库不含赛题附件、门库、论文、演示文件、原始日志或身份信息。
6. 获得竞赛规则或指导方明确的公开许可后，才把仓库从 private 改为 public。

发布审计只报告文件路径和风险类别，不输出疑似秘密原文。
